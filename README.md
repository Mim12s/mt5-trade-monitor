# MT5 Trade Monitor

Monitor trade history dan account statistics dari MetaTrader 5 secara real-time.

## Fitur

- 📊 Dashboard real-time dengan akun statistics
- 📌 Monitoring open positions
- 📜 Riwayat trading yang lengkap
- 💰 P&L tracking dan performance metrics
- 🎨 Dark theme modern UI
- 📱 Responsive design untuk mobile

## Mode

- **Live Mode**: Connects ke localhost server untuk data real-time
- **Static Mode**: Menggunakan data.json untuk viewing offline
